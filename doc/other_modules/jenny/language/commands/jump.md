# `<<jump>>`

**\<\<jump\>\>** 명령은 현재 노드의 실행을 멈추고, 곧바로 대상 노드를 실행하기 시작합니다. 많은
프로그래밍 언어의 `goto`와 비슷합니다. 예를 들면 다음과 같습니다.
```yarn
<<jump FarewellScene>>
```

이 명령의 인자는 점프할 노드의 id입니다. 일반 노드 ID로 지정하거나, 중괄호 안의 표현식으로 지정할 수
있습니다.
```yarn
<<jump {"Ending_" + $ending}>>
```

표현식이 런타임에 알 수 없는 이름으로 평가되면 `NameError` 예외가 발생합니다.
