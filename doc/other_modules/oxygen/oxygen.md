# Oxygen

```{warning}
Oxygen과 그 브릿지 패키지 `flame_oxygen`은 지원 중단(deprecated)되었습니다. 더 이상
유지보수되지 않으며 사용을 권장하지 않습니다.
```

Oxygen은 Dart로 작성된 경량 Entity Component System(ECS) 프레임워크로, `flame_oxygen` 브릿지
패키지를 통해 Flame Component System(FCS)을 대체하는 용도로 사용할 수 있었습니다.

Oxygen 패키지와 `flame_oxygen` 브릿지 패키지는 모두 지원 중단(deprecated)되었고 더 이상
유지보수되지 않으므로 사용을 권장하지 않습니다. 거의 모든 경우에 Flame Component System은
Oxygen만큼 효율적이므로, FCS를 직접 사용하는 것을 권장합니다.
