# 브릿지 패키지

:::{package} flame_3d [WIP]

Flutter GPU / Impeller의 저수준 접근을 사용해 Flame 위에서 동작하는 사용하기 편하고 **매우 실험적인**
3D 렌더링 엔진을 제공합니다.

:::{package} flame_audio

여러 오디오 파일을 동시에 재생합니다([AudioPlayers]용 브릿지 패키지).
:::

:::{package} flame_behaviors

게임 로직에 엔티티(Entity)와 비헤이비어(Behavior) 형태로 관심사 분리를 적용합니다.
:::

:::{package} flame_bloc

예측 가능한 상태 관리 라이브러리입니다([Bloc]용 브릿지 패키지).
:::

:::{package} flame_console

개발자가 게임을 디버깅하고 게임과 상호작용할 수 있게 해 주는 Flame 게임용 터미널
오버레이입니다.
:::

:::{package} flame_fire_atlas

게임용 텍스처 아틀라스를 만듭니다([FireAtlas]용 브릿지 패키지).
:::

:::{package} flame_forge2d

Box2D 물리 엔진입니다([Forge2D]용 브릿지 패키지).
:::

:::{package} flame_gamepads

게임에서 게임패드 입력을 지원합니다([gamepads]용 브릿지 패키지)
:::

:::{package} flame_isolate

isolate를 사용해 무거운 계산을 다른 스레드로 넘깁니다.
:::

:::{package} flame_lottie

Flame에서 Lottie 애니메이션을 사용합니다([Lottie]용 브릿지 패키지).
:::

:::{package} flame_network_assets

네트워크를 통해 에셋을 가져옵니다.
:::

:::{package} flame_rive

인터랙티브 애니메이션을 만듭니다([Rive]용 브릿지 패키지).
:::

:::{package} flame_riverpod

반응형 캐싱 및 데이터 바인딩 프레임워크입니다([Riverpod]용 브릿지 패키지).
:::

:::{package} flame_spine

Spine 스켈레탈 애니메이션을 사용합니다([Spine]용 브릿지 패키지).
:::

:::{package} flame_splash_screen

"Powered by Flame" 스플래시 화면을 추가합니다.
:::

:::{package} flame_svg

Flutter에서 SVG 파일을 그립니다([flutter_svg]용 브릿지 패키지).
:::

:::{package} flame_texturepacker

TexturePacker 도구로 만든 스프라이트 시트를 불러옵니다
([TexturePacker]용 브릿지 패키지).
:::

:::{package} flame_typled

가장자리 반복 패딩이 적용된 Typled 스프라이트 아틀라스를 불러옵니다([Typled]용 브릿지 패키지).
:::

:::{package} flame_tiled

2D 타일맵 레벨 에디터입니다([Tiled]용 브릿지 패키지).
:::
