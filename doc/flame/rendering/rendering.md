# 렌더링

렌더링은 게임이 플레이어에게 보이는 모든 것, 즉 스프라이트, 텍스트, 파티클 이펙트, 사용자 정의 도형을
그리는 방식입니다. Flame은 Flutter의
[Canvas](https://api.flutter.dev/flutter/dart-ui/Canvas-class.html) API를 기반으로, 스프라이트 시트 로드,
프레임 애니메이션, 비트맵 폰트를 사용한 텍스트 렌더링, 시각적 데코레이터 적용, 포스트 프로세싱 셰이더 실행을
위한 게임 지향 유틸리티를 제공합니다.
